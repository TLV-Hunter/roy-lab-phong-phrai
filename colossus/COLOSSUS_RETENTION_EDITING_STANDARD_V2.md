# COLOSSUS SIGNAL — RETENTION EDITING STANDARD V2

Updated: 2026-09-11
Status: ACTIVE — USE FOR NEW FINAL REELS

## Purpose
Upgrade Colossus Signal editing for stronger thumb-stop, watch-through and replay value without losing the slow, heavy, monumental identity.

## Governing priority
1. Story curiosity / reveal clarity
2. Continuity
3. Scale readability
4. Natural motion
5. Retention rhythm
6. Performance / atmosphere
7. Image polish

The edit must never become hyperactive, meme-like or generic short-form. Colossus remains slow and ominous; attention is renewed through meaningful information changes, not random effects.

## 1) First-frame / first-3-second rule
- First frame must already contain the strongest readable anomaly, scale reference or unresolved threat.
- No dead intro, fade-up, logo lead-in or empty establishing beat.
- Main curiosity must be readable within 0.0–1.0s.
- First on-screen hook text should appear roughly 0.15–0.45s, not after the viewer has already decided to swipe.
- Hook copy: 2–6 words preferred; use a concrete contradiction or impossible observation.
- If source begins weak, use a clean forward trim or start from the strongest early frame while preserving continuity.

## 2) Retention rhythm for 11–15s Colossus clips
Target beat map:
- 0.00–0.35s: visual anomaly already visible + micro audio cue
- 0.35–2.40s: Hook / first proposition
- 2.40–4.50s: controlled visual escalation: 2–5% push-in, parallax, local contrast shift or scale reveal
- 4.50–6.20s: pattern break / re-hook; change one meaningful dimension only
- 6.20–9.20s: reveal / second text beat / strongest evidence
- 9.20–10.80s: consequence or unresolved implication
- final 0.5–1.0s: loop bridge or visual echo back to the opening

Do not force a cut every few seconds if the story beat has not changed. Meaningful visual or audio change is preferred over arbitrary cutting.

## 3) Hook hierarchy
Choose one primary hook and at most one support hook:
A. Impossible scale — planet, moon or star used as a size reference.
B. Contradiction — the familiar object behaves incorrectly.
C. Delayed recognition — viewer sees the image first, understands the horror 1–3s later.
D. Motion anomaly — background/structure moves while reference body remains stable.
E. Observation hook — archival / scientific phrasing that sounds like discovered evidence.

Avoid vague text such as LOOK WHAT HAPPENED, YOU WON'T BELIEVE, WAIT FOR IT.

## 4) On-screen text V2
Identity remains:
- white condensed uppercase
- short cyan Signal Bar
- subtle shadow
- no hard rectangular HUD panel

Retention upgrades:
- Two text beats are the default; three only when the visual genuinely supports a third discovery.
- First beat should create a question, not explain everything.
- Second beat should reframe or escalate the first.
- Prefer 1–2 short lines, 2–7 words per line.
- Avoid text covering the anomaly, planet edge, face/eye, silhouette or strongest scale reference.
- Use quick 4–8 frame ease-in / opacity lift, not a flashy pop.
- Text exit may be slightly earlier than the reveal so the image gets a clean hero moment.

## 5) Camera-motion enhancement
Allowed when source motion is weak:
- 2–5% slow digital push-in across 2–4s
- subtle 1–2% drift / pan to preserve life in static generations
- masked depth/parallax only when edges remain natural
- controlled 3–6 frame micro punch at the exact reveal if needed
- tiny stabilized shake only for impact/event beats, never continuously

Avoid:
- constant zoom pumping
- repeated speed ramps
- handheld simulation on cosmic wide shots unless motivated
- warping planets / straight celestial edges

## 6) Pattern interrupt rules
Use 1 strong pattern interrupt in an 11–15s clip, usually around 40–55%.
Acceptable interrupts:
- momentary audio drop / silence
- new text proposition
- subtle crop/push shift
- light pulse from the actual object
- cut to a closer crop of the same event
- exposure/contrast reveal tied to the story
- one restrained low-frequency impact

Never add a random glitch, flash, whoosh or camera shake just to create activity.

## 7) Sound-design stack
Source audio remains authority unless unusable.
Layer only what supports the scene:
1. Base ambience / source bed
2. Low sub drone, very restrained
3. One signature event sound for the reveal
4. Optional high-frequency air/tension layer before reveal
5. Strategic 80–250ms micro-silence before the strongest impact/reveal

Rules:
- No repetitive whoosh on every text change.
- Avoid stock trailer booms every 2 seconds.
- Use silence as a pattern break.
- Keep final loudness around existing project target; protect transient headroom.

## 8) Light / VFX enhancement
Preferred effects are diegetic and physically motivated:
- soft local bloom / halation from existing bright source
- very subtle volumetric haze
- localized shadow expansion
- edge-light reveal
- restrained dust / particulate only when environment supports it
- tiny chromatic separation only on extreme gravitational / geometry events
- very light lens breathing at reveal

Avoid generic sci-fi HUD, heavy scanlines, random particles, constant glitch, fake lens flare stacks, hard neon boxes, artificial 4K sharpening.

## 9) Loop engineering
For clips <=15s, attempt a soft loop when story permits:
- end composition should visually rhyme with first frame
- final sound tail should lead naturally into opening ambience
- avoid obvious fade-to-black
- if using a final implication line, remove it 0.3–0.6s before cut so the opening image can restart cleanly

## 10) Source-specific decision gate
Before editing, classify source:
A. STRONG OPEN — anomaly visible immediately: preserve opening, text early.
B. SLOW OPEN — strongest frame comes later: forward-trim to first useful frame if continuity survives.
C. WEAK MOTION — enhance with slow push / local lighting / parallax only.
D. STRONG MOTION — do not over-process; let motion be the hook.
E. MORPH / ARTIFACT RISK — reject or cut around defect; effects may not hide structural failure.

## 11) Final QA — retention pass
In addition to technical QA, check:
- strongest anomaly visible by 0.5s
- curiosity understandable by 1.5s without needing the caption
- no dead visual stretch > ~3s unless tension is intentionally rising
- at least one meaningful re-hook / change before midpoint or near midpoint
- reveal occurs before final 15–20%
- text remains mobile-safe and instantly readable
- no effect distracts from scale reference
- ending does not feel like a hard accidental stop

## 12) A/B variant rule for important clips
For priority episodes, create two edit hypotheses from the same source:
- A = MONUMENTAL: slower, cleaner, maximum scale and dread
- B = RETENTION: same identity but earlier hook, stronger re-hook and slightly denser sound design

Prefer data from platform retention/hold if available rather than subjective preference alone.

## 13) Default V2 preset for new 11–12s clips
- final duration: 11.2–12.5s where source supports it
- 1080x1920
- 30fps CFR
- first hook text: 0.2–2.8s
- controlled visual escalation: 2.3–4.8s
- re-hook / pattern break: 4.8–6.2s
- second text beat / reveal: 5.7–9.3s
- clean image hero window: 8.8–10.6s
- loop bridge: final 0.5–0.8s

## 14) Source provenance / watermark rule
- Third-party watermarks present in the source must be retained in source-derived renders.
- Do not remove, cover, crop out, blur, mask or inpaint a third-party watermark as part of the editing workflow.
- If a watermark-free Final is required, obtain a clean source/export from the originating service and run the same V2 edit from that clean source.
- A clean-source replacement may preserve the previously approved timing, text, effects and sound design if the underlying visual is otherwise identical.

## Supersession rule
This file upgrades retention, text timing, sound design, pattern-interrupt use and loop behavior. It does not supersede current episode authority, visual identity, QA requirements or verified Final Reel mapping.
